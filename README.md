# 宝宝听听

给一岁左右、还不会说话的宝宝用的语音小玩具。界面做成小乖乖的声音乐园：四个地方可以逛，点进去就能听。

1. **中文儿歌** — 小兔子乖乖、两只老虎、小星星、数鸭子、拔萝卜、找朋友
2. **英文儿歌** — Twinkle Twinkle、ABC、Old MacDonald、Itsy Bitsy Spider 等
3. **动物叫声** — 先听叫声，再听中文名和英文名
4. **寓言故事** — 乌鸦喝水、龟兔赛跑、三只小猪等短故事，语速偏慢

旋律用浏览器里的小喇叭合成，歌词和故事用系统语音朗读。不需要账号，也不需要联网曲库。

## 本地运行

```bash
npm install
npm run dev -- --hostname 0.0.0.0 --port 43147
```

浏览器打开 [http://127.0.0.1:43147](http://127.0.0.1:43147)。

第一次使用请先点「点一下开始听」，这样手机和电脑才会允许出声。如果听不到说话，检查系统音量和浏览器是否允许语音。

## 给宝宝用时

- 按钮够大，宝宝可以拍，大人也可以帮着点
- 右上角可以在「大声 / 小声 / 静音」之间切换
- 播放时随时可以「停下」或「再听一遍」
