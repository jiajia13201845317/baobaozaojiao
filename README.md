# 宝宝听听

给一岁左右、还不会说话的宝宝用的语音小玩具。首页只做一件事：先听小狗叫。其余内容收进三扇门，避免一次摊开十个房间。

1. **先听小狗** — 点首页大卡片立刻听 狗 → dog → 汪汪汪
2. **认一认** — 动物、身体、家人，颜色和数字也在这里
3. **唱儿歌** — 中文儿歌、英文儿歌
4. **听故事** — 童话、古诗、寓言
5. 听过的内容会记住，下次显示「接着听」

旋律用浏览器里的小喇叭合成，歌词和故事用系统语音朗读。不需要账号，也不需要联网曲库。

## 在手机或电脑浏览器打开

请用这个公开地址，不要打开 `127.0.0.1`：那是云端开发机自己的地址，你自己的浏览器连不上。

**https://tidy-valley-592.harvis.page/?night=0**

白天模式加 `?night=0`，夜里加 `?night=1`。第一次请点「开始听」，喇叭才会出声。

更新线上页面：

```bash
npm run publish:web
```

会发布到同一个地址。

## 本地运行

```bash
npm install
npm run build
npm start
```

本机浏览器打开 [http://127.0.0.1:43147](http://127.0.0.1:43147)。

预览用的是静态导出：`next build` 写出 `out/`，再用 `scripts/serve.mjs` 提供页面。这样不会走 Next 开发服务器的跨域拦截。日常改代码可以先 `npm run build` 再 `npm start`，或用 `npm run dev` 做热更新。

如果听不到说话，检查系统音量和浏览器是否允许语音。

## 给宝宝用时

- 按钮够大，宝宝可以拍，大人也可以帮着点
- 右上角可以在「大声 / 小声 / 静音」之间切换
- 播放时随时可以「停下」或「再听一遍」
