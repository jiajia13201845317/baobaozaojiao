# 一起长大

给 1–3 岁家庭的一个应用：每天三个发展小任务、生长曲线与健康记录、疫苗清单、一只从蛋孵成小恐龙的宠物，外加宝宝自己能拍着玩的**宝宝听听**。

打开 `/` 就是全部。底部五个页签：

| 页签 | 给谁 | 做什么 |
| --- | --- | --- |
| 首页 | 大人 | 宝宝资料、当前宠物、今天的三个玩法、连续打卡、最近一次身高、下一针疫苗 |
| 早教 | 大人 | 分龄微任务、里程碑、任务库、可选的英语启蒙 |
| 听听 | 宝宝 | 儿歌、动物叫声、故事，点图就播 |
| 记录 | 大人 | 身高体重头围、体温、排便、饮食、睡眠喂养、大动作、疫苗 |
| 我的 | 大人 | 分项同意、隐私与数据、成员与权限、提醒、观看模式、成长总结 |

「宠物」不在页签里，从首页的宠物卡进去——五个已经是拇指在手机上能够到的上限。

`/grow/` 是同一个应用的另一个入口，保留是因为第一版公开链接指向那里。

所有数据只存在这台设备：档案和记录在 localStorage（键 `grow-state`，听听自己的偏好用 `bao-` 前缀），照片在 IndexedDB（`grow-media`）。没有账号，没有服务器，换台设备看不到。

## 隐私与同意

第一次打开先过一道同意页，后面才允许建档案。三条规则写在 `src/components/grow/consent-gate.tsx` 里，也是这类页面最常破的三条：

- **一项都不预勾。**直接点过去等于只同意了最少的那一项。
- **基础记录单独一项**，也是唯一必需项。「我只要一个记录本」是个能选的答案。
- **监护人身份单独确认并记时间戳**，因为记录里的人自己没法同意。

照片默认关闭。分龄内容、提醒、照片三项随时能在「我的 → 隐私与数据」里单独关掉，关掉不会删已有数据——要删有单独的入口，删除范围一条条列着，并且会真的清掉 IndexedDB 里的字节，不只是去掉引用。

没有接入任何广告、推送或行为分析 SDK。会碰到数据的第三方全部列在「我的 → 第三方清单」里。

# 宝宝听听（「听听」页签）

给一岁左右、还不会说话的宝宝用的语音小玩具，现在是主界面底部的第三个页签，皮肤和整个应用一致，颜色跟着宝宝的蛋仔走。

打开先停在开机页，只有点「开始听」才会出声——这是宝宝唯一会自己拿着手机的一屏，所以不做自动播放。切到别的页签时它保持挂载，一首歌不会因为你去记一笔就断掉。

第一下只做一件事：先听小狗叫。其余内容收进三扇门。

1. **先听小狗** — 点首页大卡片立刻听 狗 → dog → 真的狗叫（很轻的一声）
2. **认一认** — 动物、身体、家人，颜色和数字也在这里
3. **唱儿歌** — 中文儿歌、英文儿歌
4. **听故事** — 童话、古诗、寓言
5. 听过的内容会记住，下次显示「接着听」

儿歌默认走网易云的官方外链播放器。动物叫声用的是真动物录音（Wikimedia，署名见 `public/sfx/CREDITS.txt`），但每条都按「宝宝能听」的标准重做过：

- 只留一声。狗原本是连着六七声，现在按包络切出第一声就停。
- 提一点音高。狗提 35%、狮子提 30%，共振峰跟着上移，听着就从成年犬、成年狮变成小奶狗、小狮子。
- 砍掉刺耳的高频。凶不凶主要看起音和高频：狗压到 2 千赫以下，狮子 900 赫，马 1.6 千赫，大象 1 千赫。狗这条还换过素材，现在这条的频谱重心是 587 赫，之前那条 1017 赫，听感差别就在这里。
- 高频不能砍过头，砍狠了马像牛叫、大象像卡祖笛。刺不刺耳主要归淡入管，所以马和大象是「淡入拉长 + 高频只砍到还能听出是谁」。
- 淡入 50–180 毫秒，音量按 EBU R128 对齐到 −24 LUFS，峰值统一压到 −8 dBFS（约满刻度的四成）。

叫声之后没有任何配音，不会念「汪汪汪」这类拟声词。家长里可以把「动物叫声」从**真声**切成**合成**——那是本机合成的一版，比真声还轻，离线也能用。地址加 `?cry=soft` 也能直接切。

两个脚本各管一段：

```bash
node scripts/fetch-sfx.mjs   # 重新抓取并重做 12 条录音
npm run check:cry            # 量线上录音；加 -- synth 量合成兜底
```

`check:cry` 逐个量峰值、淡入和频谱重心，越界就报错，同时把 WAV 写到 `/tmp/cry` 方便试听。我们不会把曲库下载下来重分发。没网或家长改成「本地录音」时，儿歌改用本地钢琴加童声。故事和认字仍用系统语音，声调调成软一点、高一点。

# 早教与记录

**早教**一天三个 3 到 5 分钟的小任务，四个维度（大运动、精细动作与认知、语言、社交情感）轮着来。任务按日期算，同一天打开永远是同一个，不会刷新。做一个就算打卡，三个都做也行。内容做到 3 岁齐（Q1–Q8 四个阶段，共 96 个任务、16 个里程碑）。打开「英语启蒙」后，语言维度下面并排出现一条英文的，里程碑记的是「这个季度听过多少」而不是「会了多少」。

**记录**是一个统一的事件模型（`src/lib/grow/records.ts`）：每条记录就是一个事件，带 kind、时间戳、若干数字、可选的标签和照片键。加一种记录类型只要往 `KINDS` 里加一行，不用新表、不用迁移、不用新的积分规则。这里刻意没有放阈值、正常区间或结论的地方。

- **身高体重头围** 画在 WHO 参考曲线上，早产宝宝用矫正月龄。
- **体温** 只记数字、时间和测量方式，不换算、不判断高低。
- **排便 / 排尿** 一按就记，六秒内可撤销。
- **饮食** 餐次标签 + 按天的时间线 + 四个辅食阶段的性状参考 + 过敏原标签识别。不做菜品识别，不做营养分析。
- **睡眠** 睡下按一次、醒了再按一次，时长自己算——不设应该睡多久。**喂奶喝水**只记时间和次数，不记毫升。
- **大动作** 月龄参考区间写成「常在 X–Y 月龄出现」，没有逾期状态。
- **疫苗** 按 2021 年版国家免疫规划排，只是个勾选清单。

## 生长曲线的数据从哪来

`src/lib/grow/who-data.ts` 是生成的，不要手改。源头是 WHO Child Growth Standards 的 LMS 表，用

```bash
python3 scripts/build-who.py
```

从下载的 xlsx 重新生成。取值用标准的 LMS 公式 `X = M(1 + LSz)^(1/L)`，反过来算 z 分。

有一个坑值得记一下：WHO 在**第 731 天**从「躺着量的身长」换成「站着量的身高」，而 24 月龄按 30.4375 天/月四舍五入正好落在第 730 天，会取到最后一行身长。脚本里专门把 ≥24 月的取值下限顶到 731 天。生成后有 14 个点对着 WHO 公布的月龄表核对过。

## 积分分两种

**累计积分**永远是从记录实时算出来的，不单独存一个计数器——存下来的数会和家长看到的记录对不上，而且这个产品明确要求积分只增不减，算出来的就不可能缩水。**可用积分**是累计减去领养和照顾花掉的部分。

宠物只看累计升级。所以喂一次宠物、领养一只新蛋，都不会把已经养大的宠物打回去，也不会让进化进度条往回走。

其余规则也是按这个思路定的：

- 没有排行榜，不和别的孩子比。
- 积分不过期、不衰减、不清零。
- 健康记录只给 4 分，早教任务 8 分，里程碑 75 分。健康记录的分刻意压低，是为了不让「记录」变成刷分——记的数字不准，曲线就没意义了。

## 宠物

七个系列（森水风冰炎光星），每系三只小恐龙，一共 21 只。第一只蛋是送的，之后按系列花可用积分领养，同一只不会重复抽到。

每只宠物都从同一颗蛋开始：蛋仔（Lv1）→ 裂壳（Lv2）→ 破壳（Lv3），到 Lv4 才露出自己到底是哪一只。这样 21 只只需要 24 张图，拆盲盒的那一下也留住了。等级只看这只宠物领养之后攒下的累计积分。

饱腹、心情、干净三条状态每天慢慢往下掉，但有下限 35，放一周回来它只是想你了，不会看着像被虐待。喂食、玩耍、洗澡各花 6 点可用积分。三条状态跟升级完全无关——照顾是陪伴，不是任务。

宠物图是生成后处理过的，源图在 `/opt/cursor/artifacts/assets/`：

```bash
node scripts/build-pets.mjs   # 三联图按三等分切开、去底、居中，写到 public/art/pet/
```

去底是从边缘往里漫水填充白色，透明度在最后 20 级距离上渐变过渡，而不是一刀切阈值——这样每只脚底那团很浅的接触阴影能留下来，边缘也不会出现硬圈。

## 健康模块的边界

健康部分只做两件事：**记录**，以及在极端值时**提示去问医生**。

它不会说孩子偏矮、偏瘦、发育迟缓或者任何类似的判断，也不给治疗建议。百分位只陈述「同月龄同性别里大约百分之几比这个数字小」；低于 P3 或高于 P97 时，文案是「单次测量不说明什么，下次儿保带上记录请医生看看」。疫苗清单按《国家免疫规划疫苗儿童免疫程序表（2021 年版）》排，只是个勾选清单，以接种证和社区门诊为准。

首页的疫苗提醒取的是**离当前月龄最近的那一针**，不是最早没勾的那一针。家长多半是在孩子一岁多才开始用，新生儿那几针早在医院打完了只是没记上，把它当成「已超期」顶在首页只会吓人。更早的未勾项单独数出来，提示去补勾。

## 测试

```bash
npm run dev                 # 先起开发服务器
node scripts/e2e-grow.mjs   # 307 项
npx tsc --noEmit && npx eslint src
npm run check:speech        # 拟声词与话术边界
npm run check:cry           # 量动物录音的峰值、淡入、频谱重心
```

`e2e-grow.mjs` 跑的不只是功能：相当一部分断言检查的是**文案边界**——总结页不出现百分位和评价词，睡眠页不出现目标或不足，大动作页不出现逾期，饮食页不出现营养结论，界面里不出现任何竞品或借来的品牌名。这些是最容易在后续改动里悄悄破掉的部分，所以用测试钉住。

## 通知这一版做不到什么

「我的 → 提醒」里写得很直白：这是个静态站点，没有后台服务，所以**只有页面开着的时候才会提醒**。关掉页面之后不会有任何推送。写清楚会让这个功能看着没那么值钱，但换来的是家长可以自己安排——如果一个家长以为这个 App 会提醒他打疫苗，三个月后才发现它从来做不到，那是文案害了他。

调度层只有一个（`src/lib/grow/notify.ts`）：每类每天最多一次，几条同时到了只显示最要紧的那条，每天 21:00–8:00 不出声（写死的，不做成可调项）。

## 在手机或电脑浏览器打开

请用这个公开地址，不要打开 `127.0.0.1`：那是云端开发机自己的地址，你自己的浏览器连不上。

**https://shiny-hazel-646.harvis.page**

第一次打开先过同意页，再建宝宝档案（称呼、性别、生日，早产可以填矫正）。性别决定蛋仔的颜色和整个界面的配色：男宝薄荷绿，女宝樱花粉。

「听听」页签每次都先停在开机页，不会因为听过就直接进乐园。点「开始听」喇叭才出声。儿歌默认用网易云官方外链；要听本地录音，把地址加上 `source=local`，或在听听页右上角「家长」里切换音源。开机窗里有会动的天气、穿衣和吃饭提醒，点太阳、衣服或小碗会说话。想看晴天/下雨/夜里，把地址里的 `weather=` 换成 `sun`、`rain` 或 `night`；白天模式加 `?night=0`，夜里加 `?night=1`。

更新线上页面：

```bash
npm run publish:web
```

会发布到同一个地址。

## 本地运行

```bash
npm install
npm run build
npm start
```

本机浏览器打开 [http://127.0.0.1:43147](http://127.0.0.1:43147)。

预览用的是静态导出：`next build` 写出 `out/`，再用 `scripts/serve.mjs` 提供页面。这样不会走 Next 开发服务器的跨域拦截。日常改代码可以先 `npm run build` 再 `npm start`，或用 `npm run dev` 做热更新。

如果听不到说话，检查系统音量和浏览器是否允许语音。卡片上的字不会改，喇叭会按普通话、慢一点的英文来读：狗会说「小狗」，数字一不会读成「幺」，字母歌按 A B C 一个一个念。

## 给宝宝用时

- 按钮够大，宝宝可以拍，大人也可以帮着点
- 点儿歌或故事封面：正在听就停下，停着就再听一遍
- 点动物图片：只再听叫声，不会跳到下一只
- 右上角「家长」：音量、夜间、动物叫声真声 / 合成、连播 / 单曲 / 听完停、定时 10 / 20 / 30 分
- 定时到点会说「该睡觉啦」，音量和播放方式下次打开还记得
