# 宝宝听听

给一岁左右、还不会说话的宝宝用的语音小玩具。界面做成小乖乖的声音乐园，点进去就能听。

1. **动物叫声**（最前面）— 狗 → dog → 汪汪汪，点插画可以反复听
2. **身体部位** — 跟着豆豆认头、眼睛、手、脚，中英文对照
3. **我的家人** — 原创「豆豆一家」卡通小猪：爸爸妈妈爷爷奶奶哥哥姐姐宝宝
4. **认识颜色 / 数一数** — 幼儿园常学的红黄蓝和 1 到 5
5. **中文儿歌 / 英文儿歌** — 唱歌花园、星星城堡
6. **童话故事** — 小红帽、丑小鸭、白雪公主等短篇
7. **古诗背诵** — 咏鹅、春晓、静夜思等，先背原诗，再听给小朋友听的有趣白话
8. **寓言故事** — 乌鸦喝水、龟兔赛跑等

旋律用浏览器里的小喇叭合成，歌词和故事用系统语音朗读。不需要账号，也不需要联网曲库。

## 本地运行

```bash
npm install
npm run build
npm start
```

浏览器打开 [http://127.0.0.1:43147](http://127.0.0.1:43147)。

预览用的是静态导出：`next build` 写出 `out/`，再用 `scripts/serve.mjs` 提供页面。这样不会走 Next 开发服务器的跨域拦截。日常改代码可以先 `npm run build` 再 `npm start`，或用 `npm run dev` 做热更新。

第一次使用请先点「点一下开始听」，这样手机和电脑才会允许出声。如果听不到说话，检查系统音量和浏览器是否允许语音。

## 给宝宝用时

- 按钮够大，宝宝可以拍，大人也可以帮着点
- 右上角可以在「大声 / 小声 / 静音」之间切换
- 播放时随时可以「停下」或「再听一遍」
